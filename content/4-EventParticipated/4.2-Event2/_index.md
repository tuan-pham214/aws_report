### 2. Main Content and Activities

The event was organized with Swinburne Vietnam, the AWS First Cloud AI Journey community, Cloud Kinetics, and Renova Cloud. It focused on enterprise cloud architecture, real-world data work, career skills, and responsible use of AI.

#### Cloud Career Direction

Nguyen Gia Hung from AWS discussed the gap between academic knowledge and employer expectations. In addition to technical skills, students need project experience, familiarity with enterprise technologies, and the ability to connect a technical solution with business problems in finance, retail, or manufacturing. Community involvement and the ability to present personal projects are also important.

#### Academic Data vs. Real-World Data

Vinh from Renova Cloud explained that production data can be missing, duplicated, inconsistent, or interpreted differently across systems. He introduced four parts of a data platform:

- **Ingestion:** collecting data from multiple sources.
- **Processing:** cleaning, transforming, and standardizing data.
- **Storage:** retaining data in an appropriate structure.
- **Governance:** controlling access, quality, and traceability.

The session emphasized that production mistakes can affect business operations and cost, so testing, monitoring, and incident procedures are essential.

#### Soft Skills and Overcoming Fear

Nhu Tran from AWS discussed fear of failure and confidence when entering a professional environment. Simple actions such as greeting people, asking questions at the right time, and explaining a project briefly can create learning and networking opportunities.

#### Using AI for Learning and Work

Khang from Cloud Kinetics emphasized that AI can help write code, find problems, and accelerate learning, but it cannot replace foundations in networking, databases, security, and system behavior. Generated results must be reviewed and tested.

### 3. Outcomes and Value Gained

### 4. Relevance to the Internship Project

The Local AQI pipeline maps directly to the presented data-platform structure. Sensor data must be validated and standardized before forecasting. FastAPI requires input validation, logging, metrics, and explicit failures. IAM, Security Groups, CloudWatch, CloudTrail, and AWS Budgets are part of the system rather than optional work added at the end.
