During my internship from **June 15, 2025 to August 15, 2025** at **Amazon Web Services Vietnam Company Limited**, I participated in the **Workforce Bootcamp – First Cloud AI Journey** program and worked with my team on the **Local Air Quality Forecasting and Alert System** project.

My primary role in the project was **Backend/API Engineer**. I was responsible for developing the FastAPI application, deploying the backend on Amazon EC2, integrating forecast data from a SageMaker Endpoint, storing subscriber information in DynamoDB, and sending alerts through Amazon SNS. In addition to my main responsibilities, I coordinated with the ingestion, data, and machine learning members to agree on the schema, model input format, and end-to-end processing flow.

Throughout the internship, I made clear progress in deploying a feature from source code to an AWS environment, troubleshooting issues across different system layers, and discussing technical requirements with other team members. However, I still need to improve my experience in designing large-scale systems, estimating task duration, and presenting technical issues more concisely during team discussions.

## Key Achievements

- Developed a clearer understanding of how an AWS-based system is organized across ingestion, storage, processing, forecasting, API, and alerting layers.
- Developed and deployed FastAPI on EC2, tested the APIs through Swagger, and monitored system activity with CloudWatch.
- Integrated a SageMaker Endpoint into the forecast flow and connected DynamoDB and SNS to support subscription, confirmation, and threshold-based AQI alerts.
- Improved my ability to read logs, validate data contracts, write technical documentation, and prepare demo scenarios.

## Areas for Improvement

- Strengthen my knowledge of API security, user authentication, HTTPS, rate limiting, and highly available system deployment.
- Improve task estimation, feature prioritization, and time allocation for AWS integration work.
- Improve technical presentation skills by focusing on the problem, proposed solution, result, and testing evidence.
- Continue learning about time-series data and machine learning so that I can collaborate more effectively with Data/ML teams in future projects.

## Overall Reflection

I assess my internship performance as **Good**. The most important outcome was not only completing the backend portion of the project, but also understanding how the components of a cloud system work together and how a team can turn an idea into a product that can be tested, demonstrated, and handed over. This experience provides a valuable foundation for my continued development in Backend and Cloud Engineering.
